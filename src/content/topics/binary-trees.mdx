A **family tree** turned upside down. At the top is one ancestor, the **root**. Each person can have children, those children have children, and so on. Unlike a linked list, a tree **branches**: it is **non-linear** and **hierarchical**.

In a **binary tree**, each node has **at most two** children: a **left** and a **right**.

```cpp
struct Node {
    int data;
    Node* left;
    Node* right;
};
```

### The vocabulary

| Term | Meaning |
| --- | --- |
| **Root** | the top node; it has no parent |
| **Parent / child** | a node and the nodes directly below it |
| **Siblings** | children of the same parent |
| **Leaf** | a node with no children |
| **Internal node** | a node with at least one child |
| **Ancestor / descendant** | anything on the path up / down |
| **Subtree** | a node plus all its descendants |
| **Degree** | number of children of a node |
| **Depth** of a node | edges from the root down to it (root depth = 0) |
| **Level** | all nodes at the same depth |
| **Height** of a node | edges on the longest path down to a leaf |
| **Height of the tree** | height of the root |

### Special shapes

- **Full**: every node has **0 or 2** children.
- **Complete**: every level is full **except possibly the last**, which is filled **from the left**. (Heaps, later in this phase, are complete trees.)
- **Perfect**: every level is completely full. A perfect tree of height h has **2^(h+1) − 1** nodes.

### Thinking recursively

Every tree is "a root plus a left subtree plus a right subtree". So most tree functions look like this:

```cpp
int f(Node* r) {
    if (r == nullptr) return /* base value */;
    return /* combine */ (r, f(r->left), f(r->right));
}
```
