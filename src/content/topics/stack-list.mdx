An array stack is a box with a fixed number of slots. A linked-list stack is a **pile that can grow forever**: each new plate is a new node, linked to the plate under it.

The trick is choosing **which end is the top**. In a singly linked list, the **head** is the only end where both insert and delete are O(1). So:

- **push(x)** = insert at the front: `top = new Node{x, top};`
- **pop()** = delete the front: save `top`, move `top = top->next`, `delete` the old node.

There is **no `isFull()`**. The list only fills up if the whole heap runs out.

### Array or linked list?

| | Array stack | Linked-list stack |
| --- | --- | --- |
| Capacity | fixed (MAX) | grows as needed |
| Memory per item | just the value | value + pointer |
| Speed | O(1), cache-friendly | O(1), one `new`/`delete` each |
| Can overflow? | yes | no (until the heap is exhausted) |

### Application: balanced brackets

Scan the string left to right. Push every **opening** bracket. At a **closing** bracket the stack's top must be its partner; pop it. Fail if the stack is empty or the partner is wrong. At the end the stack **must be empty**.
