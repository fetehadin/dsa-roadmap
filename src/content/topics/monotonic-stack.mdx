People stand in a line, all looking right. For each person, who is the **first taller person** they can see?

Walk the line left to right with a **stack of people still waiting** for a taller person. Keep it **decreasing**: tallest at the bottom. When a new person arrives, every shorter person at the top of the stack has just found their answer: **pop** them and record it. Then push the newcomer.

```cpp
while (!st.empty() && a[st.top()] < a[i]) {
    ans[st.top()] = a[i];          // next greater
    span[st.top()] = i - st.top(); // how far away
    st.pop();
}
st.push(i);
```

Each index is pushed once and popped at most once, so the whole thing is **O(n)**.

- **Equal values**: with `<`, an equal height does not count as taller. Use `<=` if it should.
- **Circular arrays**: loop `i` from 0 to 2n − 1 and use `i % n`, pushing only during the first lap.
- **Store indices**, not values, so you can compute distances.
