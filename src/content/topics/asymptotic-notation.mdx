T(n) = 4n + 3 and T(n) = 7n + 100 look different, but for a million items both grow **in a straight line**. Asymptotic notation throws away constants and small terms and keeps only the **shape of growth** for large n. Think of describing a car as "fast" rather than "214.3 km/h".

### The five notations

Let f(n) be the running time and g(n) a simple function like n or n².

| Notation | Read as | Meaning | Like |
|---|---|---|---|
| f = **O**(g) | big-oh | f(n) ≤ c·g(n) for all n ≥ k | ≤ (upper bound) |
| f = **Ω**(g) | big-omega | f(n) ≥ c·g(n) for all n ≥ k | ≥ (lower bound) |
| f = **Θ**(g) | big-theta | both O(g) and Ω(g) | = (tight bound) |
| f = **o**(g) | little-oh | f grows strictly slower: f/g → 0 | &lt; |
| f = **ω**(g) | little-omega | f grows strictly faster: f/g → ∞ | &gt; |

### How to prove f(n) = O(g(n))

The definition says: find constants **c > 0** and **k ≥ 1** with

$$f(n) \le c \cdot g(n) \quad \text{for all } n \ge k$$

The recipe for polynomials:

1. For n ≥ 1, replace every smaller power of n by g(n) (it can only get bigger).
2. Add the coefficients. That sum is **c**.
3. The bound holds from n = 1, so **k = 1**.

**Example 1.** f(n) = 10n + 5. For n ≥ 1, 5 ≤ 5n, so 10n + 5 ≤ 15n. **c = 15, k = 1** ⇒ O(n).

**Example 2.** f(n) = 3n² + 4n + 1. For n ≥ 1, 4n ≤ 4n² and 1 ≤ n², so f(n) ≤ 8n². **c = 8, k = 1** ⇒ O(n²).

### Simplifying rules

- Drop constant factors: O(5n) = O(n).
- Keep the dominant term: O(n² + n + 1) = O(n²).
- Sequential code adds: O(n) + O(n²) = O(n²).
- Nested code multiplies: a loop of n around a loop of n = O(n²).
