A variable is a **house**; its value is the **person living there**; its address is the **street address**. A **pointer** is a slip of paper with an address written on it. It doesn't hold the person, it tells you where to find them.

```cpp
int x = 5;      // a house with 5 in it
int* p = &x;    // & = "address of": p holds x's address
*p = 10;        // * = "go to that address": changes x to 10
```

### Stack vs heap

- **Stack**: local variables. Created when a function starts, destroyed automatically when it returns. Fast, but small, and its size is fixed at compile time.
- **Heap**: memory you request at run time with **`new`**. It stays alive until **you** call **`delete`**. This is how we make data structures that grow while the program runs.

```cpp
Node* n = new Node{7, nullptr};   // lives on the heap
delete n;                          // give it back
n = nullptr;                       // don't keep a stale address
```

### Three classic bugs

1. **Null dereference**: `*p` when `p == nullptr`. Crash.
2. **Dangling pointer**: using `p` after `delete p`. Random behaviour.
3. **Memory leak**: losing the last pointer to heap memory, so it can never be freed.

> Rule of thumb: every `new` has exactly one matching `delete`. After deleting, set the pointer to `nullptr`.
