Looking for your friend in a queue of strangers, you walk from the front and check **each face** until you see them, or reach the end. That's linear (sequential) search.

### The algorithm

```text
for each index i from 0 to n-1:
    if a[i] == key: return i
return -1        (only after checking everything)
```

### Strengths and weaknesses

- ✅ Works on **unsorted** data and on **linked lists**.
- ✅ Dead simple, no preparation needed.
- ❌ Slow for big data: up to **n** comparisons.

If you'll search the same large array many times, it's worth sorting it **once** and using binary search after that.
