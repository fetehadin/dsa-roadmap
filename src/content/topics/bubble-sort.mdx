    hint: Flip one comparison. Count passes in the outer loop and print after the loop (or after `break`).
    solution: |
      ```cpp
      void bubbleSortDesc(int a[], int n) {
          int passes = 0;
          for (int i = 0; i < n - 1; i++) {
              passes++;
              bool swapped = false;
              for (int j = 0; j < n - 1 - i; j++)
                  if (a[j] < a[j + 1]) { swap(a[j], a[j + 1]); swapped = true; }
              if (!swapped) break;
          }
          cout << "passes: " << passes << "\n";
      }
      ```

---

Imagine bubbles in a glass of water: the **big ones rise to the top**. Bubble sort walks along the array comparing each pair of neighbours. If the left one is bigger, they swap. By the end of one pass, the largest item has floated to the last position, and it never moves again.

So each pass fixes one more item at the end:

- **Pass 1** puts the largest item in the last slot.
- **Pass 2** puts the second largest in the second-to-last slot.
- …and after **n − 1 passes**, everything is in place.

### The early-exit trick

If a whole pass makes **no swaps**, every neighbour pair is already in order, so the whole array is sorted. The `swapped` flag lets us stop right there. That is the "avoid late loop termination" idea from Phase 1, put into practice.

### Why the inner loop shrinks

After pass `i`, the last `i` items are final. So the inner loop only needs to go up to `n - 1 - i`. Comparing against the finished part is wasted work.

> Bubble sort is rarely used in real programs, but it is the easiest sort to reason about and a favourite for exam traces.
