      ```cpp
      void reverse(Node*& head) {
          Node* prev = nullptr;
          Node* cur = head;
          while (cur) {
              Node* next = cur->next;
              cur->next = prev;
              prev = cur;
              cur = next;
          }
          head = prev;
      }
      ```

A **treasure hunt**: each clue tells you where the next clue is hidden. You can't jump to clue #7. You must follow clues 1 → 2 → … → 7. But adding a new clue in the middle is easy: change one clue to point to the new one, and the new one to point onward.

That is a **singly linked list**: nodes scattered around the heap, each holding **data** and a **pointer to the next node**. The program only keeps **`head`**, the address of the first node. The last node's `next` is `nullptr`.

```cpp
struct Node {
    int data;
    Node* next;
};
```

### The golden rule of rewiring

When inserting, **connect the new node first, then redirect the old pointer**. If you move `head` (or `temp->next`) first, you lose the rest of the list.

### Deleting needs the node before

To remove node X you change the arrow that points **to** X, and that arrow belongs to the **previous** node. So deletion walks with a `prev` pointer. Deleting the head is a special case: there is no previous node.

### The dummy (sentinel) node

Put a fake node **before** the head: `Node dummy{0, head};`. Now every real node, including the first, has a previous node, so one loop handles all cases. At the end, `head = dummy.next`.

### Pitfalls checklist

- Check `nullptr` before every `->`.
- Handle the **empty list**, **one node**, **head** and **tail** cases.
- `delete` every node you unlink.
- Never move `head` to traverse. Use a `temp` copy.
