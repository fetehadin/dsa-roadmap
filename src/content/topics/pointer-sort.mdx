A library has 10,000 heavy books on shelves. To list them by title you don't **carry the books around**. You sort the **index cards** that say where each book is. The books never move; the cards do.

That is **pointer sort** (also called *indirect* or *index* sort).

### The problem it solves

Each swap in a normal sort copies whole items. If each item is a big `struct` (name, ID, address, photo…), every swap copies hundreds of bytes three times. That's slow.

### The trick

1. Make an array of pointers: `p[i] = &records[i]`.
2. Run any sort on **p**, but compare through the pointers: `p[j]->score < p[min]->score`.
3. Swap **pointers**: `swap(p[i], p[min])`. Each swap moves 8 bytes.
4. Read records in order through p: `p[0]->name`, `p[1]->name`, …

The original array keeps its order. You can even keep **several pointer arrays** (by name, by score, by ID) over the same data at once.
