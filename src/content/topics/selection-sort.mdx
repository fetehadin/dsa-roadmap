          for (int end = n - 1; end > 0; end--) {
              int maxIdx = 0;
              for (int j = 1; j <= end; j++)
                  if (a[j] > a[maxIdx]) maxIdx = j;
              swap(a[maxIdx], a[end]);
          }
      }

You're picking a football team, best player first. You look at **everyone** still available, pick the best, and they step forward. Then you look at everyone remaining again… That is selection sort, except we pick the *smallest* each time.

### The idea

The array has two parts: a **sorted** part on the left (initially empty) and an **unsorted** part on the right.

1. Scan the unsorted part to find the **minimum**.
2. **Swap** it with the first unsorted item. The sorted part grows by one.
3. Repeat n − 1 times.

### Why it's always O(n²)

To be sure an item is the minimum, you must look at every remaining item. Pass 1 makes n − 1 comparisons, pass 2 makes n − 2, and so on:

$$(n-1) + (n-2) + \dots + 1 = \frac{n(n-1)}{2}$$

That happens **no matter what the input is**, even if it's already sorted.

### Its one strength

It does **at most n − 1 swaps**. If moving data is very expensive (huge records, flash memory), that matters. For huge records, see *pointer sort* next.
