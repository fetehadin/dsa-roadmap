A **train**: every carriage is coupled to the one in front **and** the one behind. You can walk through the train in either direction, and to unhook a carriage you only need that carriage, because it knows both neighbours.

```cpp
struct DNode {
    int data;
    DNode* prev;
    DNode* next;
};
```

We usually keep both **`head`** and **`tail`**, which makes inserting and deleting at **either end O(1)**.

### Updating both directions

Every insert or delete updates up to four pointers. A safe order for inserting `n` between `A` and `B`:

1. `n->prev = A; n->next = B;` (the new node first; nothing is lost yet)
2. `A->next = n; B->prev = n;`

For deleting `cur`: `cur->prev->next = cur->next;` and `cur->next->prev = cur->prev;`, and check for `nullptr` at the head and the tail.

### When to use it

Browser back/forward history, music playlists (previous/next), undo/redo, and any "delete this node now" situation. Pay the extra pointer when you need to move backwards.
