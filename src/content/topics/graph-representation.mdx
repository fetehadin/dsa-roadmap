Two ways to write down who knows whom in a class.

**A big table** (adjacency matrix): rows and columns are students, and you put a 1 where two students know each other. Checking any pair is instant, but a class of 1,000 needs a million cells, mostly zeros.

**A contact list per student** (adjacency list): each student keeps a list of only the people they know. It is compact, and listing a student's friends is fast. But checking "does A know B?" means scanning A's list.

### Adjacency matrix

```cpp
int m[V][V] = {};
m[u][v] = m[v][u] = 1;   // undirected edge u–v
```

- Space **O(V²)**, whatever the number of edges.
- Edge check **O(1)**.
- Symmetric for undirected graphs. For weighted graphs, store the weight instead of 1.

### Adjacency list

```cpp
vector<vector<int>> adj(V);
adj[u].push_back(v);
adj[v].push_back(u);     // undirected: both ends
```

- Space **O(V + E)**.
- Looping over neighbours costs only **deg(u)**.

### Which one?

- **Sparse** graphs (most real ones): **list**.
- **Dense** graphs, or when you need many fast "is there an edge?" checks: **matrix**.
