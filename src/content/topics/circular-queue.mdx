Picture a **revolving sushi belt** with N plates. The chef places food on the next empty plate; diners take food from the oldest plate. When the chef reaches the end of the belt, they just carry on at the start. Nothing is wasted.

A circular queue is the same fixed array as before, but we treat it as a **ring**. When an index reaches the last slot, the next step takes it back to **0**:

```cpp
rear  = (rear + 1) % N;   // enqueue
front = (front + 1) % N;  // dequeue
```

So the slots freed by dequeue are reused by later enqueues. Every operation is still **O(1)**.

### Full or empty?

With only `front` and `rear`, a full ring and an empty ring can look the same. Two common fixes:

1. **Keep a `count`** (this page): empty when `count == 0`, full when `count == N`.
2. **Leave one slot unused**: empty when `front == rear`, full when `(rear + 1) % N == front`.

Textbooks and interviewers use both. Know both.

### Printing in order

Start at `front` and step `count` times: `k = (k + 1) % N`. Do not just print `q[0..rear]`.
