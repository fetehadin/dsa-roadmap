You drop a stone in a pond. The ripples spread out **ring by ring**: everything 1 step away, then 2 steps, then 3. That is **Breadth-First Search**.

Now you explore a maze. You follow one corridor **as far as it goes**, and only when you hit a dead end do you **back up** to try the last turn you skipped. That is **Depth-First Search**.

### BFS: use a queue

1. Mark the start visited and enqueue it.
2. While the queue is not empty: dequeue u, process it, and enqueue every **unvisited** neighbour (marking it visited **now**).

The queue makes vertices come out in order of distance. So BFS gives the **shortest path in edges**.

### DFS: use a stack (or recursion)

```cpp
void dfs(int u) {
    visited[u] = true;
    cout << u << " ";
    for (int v : adj[u])
        if (!visited[v]) dfs(v);
}
```

The recursion **is** a stack: the call stack remembers where to back up to. An iterative version uses `std::stack`.

### Why "visited"?

Trees have no cycles, so tree traversals never revisit a node. Graphs can have cycles: 0 → 1 → 4 → 3 → 0 → … would loop forever. The **visited** array makes sure every vertex is processed **once**.

### Cost

Each vertex is enqueued (or called) once, and each edge is checked once from each end: **O(V + E)** with an adjacency list. With a matrix, finding a vertex's neighbours scans a whole row, so **O(V²)**.

> Tree level-order traversal (Chapter 6) is just BFS on a tree.
