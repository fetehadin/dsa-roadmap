A **library** puts every book on a shelf chosen by the first letter of the author's surname. To find "Tamassia" you walk straight to shelf **T**. You don't search the whole library. That shelf rule is a **hash function**.

### The idea

A **hash function** `h(key)` turns a key into an index of an array (the **hash table**) of size M. A common simple one:

```cpp
int h(int key) { return key % M; }   // M is often a prime
```

Store the key at `table[h(key)]`; to search, look in the same place. **No scanning**, so it is O(1) on average.

A good hash function is **fast** and **spreads keys evenly**.

### Collisions

Two keys can map to the same index (14 and 21 both give 0 when M = 7). Two classic fixes:

- **Separate chaining**: each slot holds a **linked list**. Colliding keys join the list.
- **Open addressing (linear probing)**: if the slot is taken, try the **next** one, `(h + 1) % M`, then `(h + 2) % M`, … until an empty slot. Searching stops at an **empty** slot.

### Load factor

**α = n / M**: how full the table is. As α grows, chains get longer and probe runs get longer. With probing, α must stay below 1 (keep it under about 0.7). With chaining, the table can still work above 1, but it gets slower.

> In C++, `std::unordered_map` and `std::unordered_set` are hash tables.
