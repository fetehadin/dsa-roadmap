You are visiting every room in a building. **Depth-first** means you go down one corridor to the end before trying the next. **Breadth-first** means you visit every room on floor 1 before going to floor 2.

### The three depth-first orders

All three go **left before right**. They differ only in **when you visit the node itself**:

| Order | Rule | Memory trick |
| --- | --- | --- |
| **Preorder** | **N**ode, Left, Right | node comes **pre** (before) |
| **Inorder** | Left, **N**ode, Right | node is **in** the middle |
| **Postorder** | Left, Right, **N**ode | node comes **post** (after) |

```cpp
void inorder(Node* r) {
    if (!r) return;
    inorder(r->left);
    cout << r->data << " ";
    inorder(r->right);
}
```

Move the `cout` line up for preorder, down for postorder.

### What each is good for

- **Preorder**: copying a tree, printing folder structures.
- **Inorder**: a BST in **sorted order**.
- **Postorder**: deleting a tree (children before parent), evaluating expression trees.

### Level order (breadth-first)

Use a **queue**: push the root; repeatedly pop a node, print it, push its left and right children. The queue makes sure nodes come out level by level, left to right. This is BFS, which you will meet again on graphs in Chapter 7.
