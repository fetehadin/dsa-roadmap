A **map of cities and roads**. The cities are **vertices** (nodes); the roads are **edges**. Unlike a tree, there is no root and no parent: any city can connect to any other, and you can drive in circles.

A graph is written **G = (V, E)**: a set of vertices and a set of edges.

| Term | Meaning |
| --- | --- |
| **Adjacent** | two vertices joined by an edge |
| **Degree** | number of edges at a vertex |
| **Path** | a sequence of vertices joined by edges; its **length** is the number of edges |
| **Cycle** | a path that returns to its start without reusing an edge |
| **Connected** | there is a path between every pair of vertices |
| **Weighted** | each edge carries a number (distance, cost, time) |
| **Directed** | edges are one-way arrows (next topics) |

### Trees are graphs too

A **tree** is a connected graph with **no cycles**. It always has exactly **V − 1** edges. Add one more edge and a cycle appears.

### The handshake rule

Every edge has two ends, so it adds 1 to the degree of **two** vertices. The sum of all degrees is therefore **2E**. This is a favourite short-answer question.
